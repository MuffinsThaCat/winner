======================================================================
CLARIFICATION: RETH vs REVM
======================================================================

RETH = Full Ethereum client (node software by Paradigm)
  - Handles networking, consensus, block propagation
  - Can use different execution engines

REVM = Execution engine (EVM implementation in Rust)
  - Just processes transactions
  - Used by Reth, Foundry, Arbitrum, and many others

SupraBTM = REVM + their parallel execution strategy (iBTM)
Williams = REVM + sequential execution with bulk prefetch
